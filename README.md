\# ZigWheels Capstone Project



QA automation Capstone project based on the \[ZigWheels](https://www.zigwheels.com/) website.



The project demonstrates a professional QA framework using functional, accessibility, performance, and security testing techniques.



\## Project Status



🚧 \*\*In Development — Sprint 0: Project Foundation\*\*



The framework is currently being established using an Agile development workflow.



\## Technology Stack



\- C#

\- .NET 8

\- NUnit

\- Reqnroll / BDD

\- Selenium

\- Playwright

\- Apache JMeter

\- OWASP ZAP

\- Docker

\- Selenium Grid

\- Allure

\- Git \& GitHub
